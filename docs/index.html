Organizations I've designed for

I help teams turn complex rules and legacy systems into products people can actually use.

How I work

  1. 1

    Start with an audit

    Accessibility, information architecture and support tickets show where people get stuck before anyone redesigns anything.

  2. 2

    Build access in

    WCAG AA and Section 508 are part of the foundation, not a checklist at the end.

  3. 3

    UX before UI

    When usability and looks compete, usability wins. On WorkRadar, a sortable table beat prettier cards because managers needed to compare data fast.

  4. 4

    Stay with it

    Regulated products change with every new rule, so the design keeps evolving with them.
