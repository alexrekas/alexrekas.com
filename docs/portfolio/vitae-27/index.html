Vitae 27

Vitae 27 is the design system behind IdeaCrew's Enroll platform, which runs health insurance marketplaces for Washington DC, Maine and Massachusetts. I built it by directing an AI coding agent: I made the design decisions and reviewed the output, and the agent wrote the code. One token set themes all three state brands in light and dark mode, and every change is checked for accessibility automatically.

One system, three brands

Each state marketplace has its own brand, but they all run on the same product. Instead of maintaining three sets of components, Vitae 27 uses one token set for color, type and spacing that switches between the DC, Maine and Massachusetts brands, each in light and dark mode. A fix made once shows up in every market.

From Figma to production

The system runs in one line from Figma to Storybook to the Rails components engineers ship. I directed an AI coding agent to build that pipeline and the components in it. My job was the part that needs a designer: deciding what each component should do, writing the rules, and reviewing every result against the Figma source before it shipped.

Accessibility on every change

WCAG 2.1 AA checks and visual-regression tests run automatically in CI. If a change breaks contrast, focus states or layout in any brand, it's caught before it reaches a state's marketplace.
